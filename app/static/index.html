Prima della proiezione

CosaGuardo prende titoli, locandine e piattaforme da TMDB. Serve una chiave gratuita, da inserire una sola volta.

  1. Crea un account su themoviedb.org.
  2. Apri Impostazioni → API e richiedi una chiave per uso personale.
  3. Copia la API Key (o la API Read Access Token) e incollala qui sotto.
